Welcome to RickWire

Wubba lubba dub dub! Let's get you set up. It takes about a minute.

RickWire downloads in two ways:

  • 🧲 Torrents, magnets and file-hoster links (MEGA, Rapidgator, 1fichier…) go through a debrid service. That's a paid account (usually a few dollars a month) that fetches the file on its own fast servers, then RickWire pulls it down to your PC over HTTPS. Your PC never joins the torrent swarm.
  • 📺 YouTube, Tubi, archive.org, .mpd / .m3u8 and other media links use yt-dlp and work without a debrid account.

Your API key is stored in Windows Credential Manager. It is never written to a file, never shown again and never sent to your phone.

Pick your debrid service

Already have an account? Choose it and paste your API key. Don't have one yet? Use Sign up, or skip and add it later in ⚙ Settings.

Media tools

For YouTube and other media sites RickWire uses yt-dlp, ffmpeg (joins video and audio) and Deno (YouTube requires it). They come from each project's official GitHub releases, and every file's checksum is checked before use.
