## ⚠️ Pre-release: the Mac version is untested

This is the first build of RickWire for **macOS**. It passes automated tests on GitHub's Apple Silicon Mac (it
starts, shows its window and menu-bar icon, opens magnet links and .torrent files, saves keys in the Keychain,
downloads ffmpeg/Deno and quits cleanly), but **nobody has used it on a real Mac yet**. Expect rough edges, and
please report what you find.

### Mac: how to try it
- Needs an **Apple Silicon** Mac (M1 or newer) on **macOS 12** or later.
- Download `RickWire-0.2.8-mac-arm64.dmg`, open it and drag **RickWire** into **Applications**.
- **First launch: right-click RickWire › Open, then Open again.** The app isn't notarized by Apple, so a normal
  double-click says it "can't be opened". If it still refuses: *System Settings › Privacy & Security* › **Open Anyway**.
- RickWire lives in the menu bar (the portal icon). Closing the window keeps it running; quit from that menu or ⌘Q.

### Also in 0.2.8 (all platforms)
- **Fix:** ffmpeg downloads work again. The ffmpeg build site (BtbN) moved and renamed its files on Nov 12, 2026,
  so 0.2.7's *Settings › Media tools* couldn't find ffmpeg.
- **Fix:** the desktop's own LAN address lookup is cached, so the settings page no longer waits on a slow
  network-name lookup.

Windows and Linux files are included as usual. Windows users can stay on 0.2.7 unless they need the ffmpeg fix.
