## ⚠️ The Mac version is new and untested

This is the first release with a **macOS** build. It passes automated tests on GitHub's Apple Silicon Mac (it
starts, shows its window and menu-bar icon, opens magnet links and .torrent files, saves keys in the Keychain,
downloads ffmpeg/Deno, does a Magic Wormhole transfer and quits cleanly), but **nobody has used it on a real Mac
yet**. Expect rough edges, and please report what you find.

### Mac: how to try it
- Needs an **Apple Silicon** Mac (M1 or newer) on **macOS 12** or later.
- Download `RickWire-0.2.8-mac-arm64.dmg`, open it and drag **RickWire** into **Applications**.
- **First launch: right-click RickWire › Open, then Open again.** The app isn't notarized by Apple, so a normal
  double-click says it "can't be opened". If it still refuses: *System Settings › Privacy & Security* › **Open Anyway**.
- RickWire lives in the menu bar (the portal icon). Closing the window keeps it running; quit from that menu or ⌘Q.

### New: 🕳 Magic Wormhole (all platforms)
- **Receive:** paste a wormhole code (like `7-crossover-clockwork`) into the download box, on the PC or a phone.
- **Send:** **🕳 Send…** next to *Download* (or **📤** on a finished download) shows a code and a QR code to give
  the other person. They can use RickWire, the `wormhole` command, Warp, Wormhole William or Destiny.
- Encrypted end to end. Both sides must be online at the same time; each code works once.
- Settings › *Downloads* › *Magic Wormhole*: size limit for incoming transfers, and your own relay servers.

### Fixes
- ffmpeg downloads work again. The ffmpeg build site (BtbN) moved and renamed its files on Nov 12, 2026, so
  0.2.7's *Settings › Media tools* couldn't find ffmpeg.
- The settings page no longer waits on a slow network-name lookup (the LAN address is cached).

### Updating on Windows
Run `RickWire-Setup-0.2.8.exe`; it installs over 0.2.7 and keeps your settings, keys, phones and queue.
